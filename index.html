Engineering approach

Purpose before code.

I believe great software starts with understanding the problem before writing the code. I focus on building solutions that are simple, scalable, maintainable, and useful to real users. I value clean architecture, thoughtful design, continuous learning, and solving problems with purpose—not just writing code.

I start by sketching the flow before opening the editor, ship the smallest usable version early, and improve it with feedback. I keep code readable, document the decisions that matter, and treat every project as a chance to learn something new.
